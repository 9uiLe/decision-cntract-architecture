# J 予約の利用停止

![予約の利用停止を現在状態の判断と拒否理由の表示で扱う。停止後は受付作成要求を送らず、受付済みの記録を読み出せる。](../assets/experiment-j.svg)

予約に利用停止を追加します。利用停止中の予約から新しいチェックインを作成できません。予約の成立履歴と、既に受け付けた記録は維持します。シミュレーターで利用停止を設定します。

## 確認する変更

予約を来場受付で利用できるか判断する箇所で、利用停止の分岐漏れを検出します。来場受付 Core が有効な予約の確認だけを受け取る構成では、その処理に新しい結果の分岐を要求する必要はありません。

対応後は、利用停止された予約から受付作成要求を送らないこと、既存の受付記録を読み出せること、受付利用可否と取消期限が独立していることを確認します。参加資格 Core のルールは維持します。
