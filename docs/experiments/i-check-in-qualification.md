# I 来場時の資格再確認

予約成立時に必要だった資格を、来場受付でも対象参加者ごとに確認します。資格不要で成立した予約には、現在有効な予約と受付時間の条件を適用します。

## 確認する変更

来場受付の契約に、現在有効な予約の確認と、対象参加者について有効と確認された資格を要求します。予約の確認だけを渡す旧経路はコンパイル検証の対象です。別の参加者の資格確認を渡す場合は、実行時に対象の不一致を検出します。資格期限は参加資格 Core が判定します。

予約時に A・B とも資格が有効で、来場時に B だけが失効している予約を使います。基準仕様では両方を受け付けられます。この課題では A だけ受け付けられ、B の受付作成要求は発生しません。予約の成立と取消の条件は維持します。
