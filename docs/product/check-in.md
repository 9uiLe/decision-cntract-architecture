# 来場受付

来場受付は、現在有効な予約に含まれる参加者を一人ずつ受け付ける操作です。2人の予約で片方を受け付けても、もう片方は未受付のままです。

## 受付条件

予約 Core が、予約の現在の有効性と、その予約に対象参加者が含まれることを確認します。来場受付 Core はその確認と、受付時刻、参加者ごとの受付状態から受付の可否を判断します。開催開始時刻を `T`、判定時刻を `now` とすると、受付時間は `T - 30分 <= now < T + 15分` です。

基準仕様では、有効な予約に含まれる参加者を受け付けるときに資格を再確認しません。過去に成立したという記録と、現在有効な予約の確認は区別します。たとえば `T - 72時間` に作成した予約を `T - 48時間` に取り消した場合、`T - 20分` に取消前の情報を渡しても受付要求を送信しません。

## 受付結果と照会

参加者ごとに未受付、受付処理中、受付済み、受付結果不明を扱います。成立していないと確定した場合は、利用者の明示操作で新しい試行を開始できます。同じ試行の再タップや画面復帰は外部への要求を増やしません。

成立応答が失われた場合は元の受付要求を照会します。予約作成と来場受付は別の要求識別子を使います。照会で受付済みと確認できた場合は、元の参加者の受付だけを更新します。
