# 参加資格

通常回では資格の確認なしに予約へ進めます。上級回では、開催回が指定した講習の修了資格を全参加者が保有している必要があります。

## 参加者ごとの確認結果

参加資格 Core は、参加者と必要な資格の組を指定して保有状況を照会します。結果は有効、未取得、期限切れ、確認結果不明に分かれます。資格の有効期限を `expiresAt`、判定時刻を `now` とすると、`now < expiresAt` の場合に有効です。

確認結果不明では、利用者は資格を再照会できます。再照会は予約作成を開始しません。外部入力の形式が変わる場合は、Adapter がサービスの値を解釈し、参加資格 Core へ観測結果を渡します。

## 要資格回の予約送信

予約 Core は、現在の開催回に必要な資格と、現在選んでいる参加者集合を確認します。有効な資格確認は、その確認が対象とする参加者本人にだけ使えます。人数が一致していても、異なる参加者の確認や、同じ参加者の確認の重複では不足を補えません。

開催回・参加者・必要な資格のいずれかが変わった場合は、変更後の条件で確認します。予約の送信と再試行の前に、参加資格 Core が全員分を照会し、一つの時刻で資格を判定します。その時刻に資格が失効している参加者がいれば、予約作成の要求を送信しません。[判定時刻と送信期限](contract-evidence.md#判定時刻)

基準仕様の成立済み予約は、予約後に資格の期限を迎えても維持します。来場時に資格を確認する仕様は[変更課題 I](../experiments/i-check-in-qualification.md)で扱います。
